一、圆圈大小 —— 呼吸节拍器
变的规则

一个完整呼吸周期 = 吸气时间 + 呼气时间

比如：
  频率 8 bpm（每分钟8次呼吸） → 一个周期 60÷8 = 7.5 秒
  比例 5:5                  → 吸气 3.75 秒 + 呼气 3.75 秒

圆圈大小变化范围：
  吸气最大：圆圈的 142%（比正常大一圈）
  呼气最小：圆圈的 72%（比正常小一圈）

二、圆圈颜色 —— 呼吸和心跳的「合拍度」
模式 2：共振组测试（Control Group / 0.1Hz）

这个模式下颜色变成核心反馈，它实时告诉你：你的心率变异性（HRV）是不是锁在了呼吸频率上？

什么是「频率锁定（Entrainment）」？

心脏有一个很妙的机制叫呼吸性窦性心律不齐（RSA）：吸气时心率加快，呼气时心率减慢。当你在 0.1Hz（6 次/分钟）的频率下深呼吸时，如果 HRV 的功率高度集中在呼吸频率附近，就说明你的自主神经系统被成功「牵引」到了这个频率 —— 这就是共振状态。

系统用频域分析来衡量这个效果：

1. 取最近 60 秒的心率数据 → 重采样到均匀时间网格
2. 用 Goertzel 算法（单频点 DFT）计算呼吸频率附近的功率
   扫描范围：0.08 Hz ~ 0.12 Hz（即 0.1 ± 0.02 Hz）
3. 计算这个频带的功率 ÷ 总 HRV 功率 = 频率锁定分数

得到一个 0 到 1 的「频率锁定分数（Entrainment Score）」：

为什么用频域分析而不是波形相关？

之前用的是时间域互相关（比较心率波形和呼吸正弦波有多像），但这个方法有两个问题：

1. 窗口太短：60 秒窗口只有 6 个呼吸周期，波形对齐不稳定
2. 相位敏感：每个人心率响应呼吸的相位不同（有人在吸气初心率就升，有人到吸气末才升），互相关需要额外搜索相位偏移

换成频域分析后：
- 不需要关心心率和呼吸之间的相位关系 —— 只看「功率是不是集中在 0.1Hz」
- 对 60 秒窗口更稳定 —— 即使只有几个周期，频率能量也能可靠估计
- 天然处理了弱 HRV（分数自然低）和跑偏的强 HRV（功率在错误频率 → 分数也低）

三、粒子绽放 —— LF Power 达标奖励

LF Power 是什么？

LF Power（低频功率，单位 ms²）是心率变异性（HRV）分析中最重要的指标之一。当你在共振频率下呼吸时，LF 频段（0.04~0.15Hz）的能量会显著升高 —— 这说明你的压力反射系统正在高效工作。简单理解：LF 越高，身体越放松、越在状态。

绽放怎么触发？

不是 LF 一高就放，而是有一套「防手滑」逻辑：

✅ 条件 1：LF ≥ 阈值（默认 500 ms²）
✅ 条件 2：连续 3 秒都达标（排除偶发的运动伪差）
✅ 条件 3：距离上次绽放 ≥ 2 分钟（避免太频繁，保持新鲜感）
✅ 条件 4：本场最多绽放 5 次（稀缺性 → 动力）
两个绽放之间的进度怎么看？

虽然没有直接的进度条，但系统内部会根据两个因素计算「离下次绽放还有多远」：
- 时间因素：距离上次绽放越久 → 进度越高
- LF 因素：当前 LF 越高 → 进度涨得越快（最高 2 倍速）

LF 持续高的时候，你可能不到 2 分钟就能触发下一次绽放。
