# CDI-PRBF 视觉反馈设计说明

> 面向飞书文档的轻松可读版本 —— 不讲代码实现，只讲「为什么这样设计」和「怎么变」

---

## 一句话说清楚

CDI-PRBF 测试里，**Interface A（图形化界面）** 用三个视觉通道同时给你反馈：

| 你看到的 | 它反映什么 | 怎么变的 |
|:---|:---|:---|
| 🔵 **圆圈大小** | 呼吸节奏引导 | 吸气变大 → 呼气变小，跟着它的节奏呼吸就行 |
| 🎨 **圆圈颜色** | 你的呼吸和心跳「合拍」程度 | 越合拍颜色越蓝（白→浅蓝→天蓝→深蓝四档） |
| ✨ **粒子绽放** | 你的 LF Power（心率变异性）达标了 | LF 连续3秒≥阈值 → 屏幕中央爆发彩色粒子 |

**一句话总结：跟着圆圈大小呼吸 → 让圆圈颜色变蓝 → 触发粒子绽放奖励。**

---

## 一、圆圈大小 —— 呼吸节拍器

### 它怎么带你呼吸？

界面上有一个会「呼吸」的圆圈，你需要**跟着它的节奏**吸气和呼气：

- **圆变大** = 该吸气了 🤿
- **圆变小** = 该呼气了 😤

圆圈外围还有一圈圆环，顺时针跑满一圈 = 完成一个完整呼吸。

### 变的规则

```
一个完整呼吸周期 = 吸气时间 + 呼气时间

比如：
  频率 8 bpm（每分钟8次呼吸） → 一个周期 60÷8 = 7.5 秒
  比例 5:5                  → 吸气 3.75 秒 + 呼气 3.75 秒

圆圈大小变化范围：
  吸气最大：圆圈的 142%（比正常大一圈）
  呼气最小：圆圈的 72%（比正常小一圈）
```

### 为什么不是线性变大变小？

圆圈用的是一种**缓入缓出**的节奏 —— 每次吸气和呼气开始/结束时慢一点，中间快一点。这和真实横膈膜呼吸的感觉更接近，比匀速放大缩小更自然。试想一下：你吸气不是匀速吸到底的，而是中间吸得快，快吸满时慢下来。

## 二、圆圈颜色 —— 呼吸和心跳的「合拍度」

颜色有两个模式，取决于你选的测试类型。

### 模式 1：扫频测试（Find PRBF）

这个模式下颜色**很简单**，只告诉你当前是吸气还是呼气：

- 🔵 **蓝色** = 吸气中
- 🟢 **绿色** = 呼气中

颜色不反映你的生理状态，纯粹是呼吸阶段的辅助提示。

### 模式 2：共振组测试（Control Group / 0.1Hz）

这个模式下颜色**变成核心反馈**，它实时告诉你：**你的心跳跟呼吸「合拍」了吗？**

#### 什么是「合拍」？

心脏有一个很妙的机制叫**呼吸性窦性心律不齐（RSA）**：吸气时心率自然加快，呼气时心率自然减慢。当你在 0.1Hz（6 次/分钟）的频率下深呼吸时，如果心跳和呼吸的「波」对齐得好，就说明你的自主神经系统处于良好的共振状态 —— 这就是我们要的效果。

系统会实时计算你的**心率波形**和**呼吸正弦波**之间的相关性（用互相关算法 + 时间对齐搜索），得到一个 **0 到 1** 的分数：

| 分数 | 含义 |
|:---|:---|
| 0.0 | 心跳和呼吸完全不搭 🤷 |
| 0.5 | 还行，有一半时间对上了 |
| 1.0 | 完美共振！心率完美跟随呼吸 🎯 |

#### 颜色怎么变？

为了避免颜色频繁闪烁（会让用户困惑），系统用了**四个稳定档位**：

| 档位 | 合拍分数 | 圆圈颜色 | 含义 |
|:---:|:---|:---|:---|
| 0 | < 0.4 | ⬜ 白色 | 还没对上，继续调整呼吸 |
| 1 | 0.4 ~ 0.6 | 🔹 浅蓝 | 开始有感觉了 |
| 2 | 0.6 ~ 0.8 | 🔷 天蓝 | 不错，在正确轨道上 |
| 3 | ≥ 0.8 | 💙 深蓝 | 很棒！深度共振中 |

#### 为什么不直接用连续渐变色？

因为人眼很难判断「蓝色是不是比刚才深了一点点」。四档分级的颜色 + 需要连续3秒稳定在某个档位才会切换（防抖设计），让你能清晰地感知到「我进步了」或「我退步了」，而不是看到颜色像变色龙一样飘忽不定。

#### 前60秒为什么不看颜色？

测试开始后的前60秒是**校准期**，这段时间颜色可能不太准（因为数据还不够多）。建议这段时间专注于跟着圆圈节奏呼吸，先别纠结颜色。

## 三、粒子绽放 —— LF Power 达标奖励

### LF Power 是什么？

LF Power（低频功率，单位 ms²）是心率变异性（HRV）分析中最重要的指标之一。当你在共振频率下呼吸时，LF 频段（0.04~0.15Hz）的能量会显著升高 —— 这说明你的压力反射系统正在高效工作。简单理解：**LF 越高，身体越放松、越在状态。**

### 绽放怎么触发？

不是 LF 一高就放，而是有一套「防手滑」逻辑：

```
✅ 条件 1：LF ≥ 阈值（默认 500 ms²）
✅ 条件 2：连续 3 秒都达标（排除偶发的运动伪差）
✅ 条件 3：距离上次绽放 ≥ 2 分钟（避免太频繁，保持新鲜感）
✅ 条件 4：本场最多绽放 5 次（稀缺性 → 动力）
```

四个条件**全部满足** → 🎆 屏幕中央爆发 100 颗彩色粒子！

### 粒子长什么样？

- **颜色**：青蓝到紫罗兰色系（不是绿色/蓝色，避免和圆圈颜色混淆）
- **运动**：从中心向四周射出，受「重力」影响往下坠
- **效果**：带发光阴影的半透明粒子，大概 1~2 秒就消散了

### 为什么用绽放而不是持续粒子？

持续粒子（比如一直飘）容易变成「背景噪音」，你会慢慢忽略它。而**离散的突发绽放**是一个明确的事件信号 —— 像游戏里拿到成就时的特效 —— 它告诉你「你做对了！」，而且因为每次绽放之间有冷却时间，你会期待下一次，这种期待本身就是一种激励。

### 两个绽放之间的进度怎么看？

虽然没有直接的进度条，但系统内部会根据两个因素计算「离下次绽放还有多远」：
- **时间因素**：距离上次绽放越久 → 进度越高
- **LF 因素**：当前 LF 越高 → 进度涨得越快（最高 2 倍速）

LF 持续高的时候，你可能不到 2 分钟就能触发下一次绽放。

## 四、总结：三个通道如何协同工作

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│   你看到一个大圆圈，跟着它的节奏呼吸                   │
│              ↓                                      │
│   圆圈大小 = 呼吸节拍器（跟着走）                      │
│   圆圈颜色 = 做得好不好（越蓝越好）                    │
│   粒子绽放 = 里程碑奖励（LF达标了！）                  │
│                                                     │
│   三者关系：                                         │
│   · 大小是你「要做什么」—— 外源引导                    │
│   · 颜色是你「做得怎样」—— 实时生理反馈                │
│   · 粒子是「做对了的奖励」—— 正向激励                  │
│                                                     │
└─────────────────────────────────────────────────────┘
```

## 五、和 Interface B（游戏化界面）的对应关系

两个界面共享**完全相同的传感管道和算法**，只是表现方式不同：

| 信号 | Interface A（图形化）| Interface B（游戏化） |
|:---|:---|:---|
| 呼吸引导 | 圆圈大小缩放 | 云朵大小变化 |
| 共振分数 | 圆圈颜色（白→蓝四档）| 云朵颜色 |
| LF Power | 粒子绽放效果 | 花朵数量 |

这种设计保证了**视觉表现风格**是唯一的自变量 —— 你可以对比「看抽象圆圈」和「看云朵花园」两种体验，而不用担心反馈逻辑不同带来的干扰。
